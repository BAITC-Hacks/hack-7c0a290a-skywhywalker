# Проверка единой версии MoneyGraph AI

Дата: 23 сентября 2026.

## Обновление `feat/jury-agent-workspace`

Проверки ниже относятся к новому рабочему экрану и ограниченному агенту. Они отделены от исторической проверки базовой версии.

### Автоматические проверки и официальный набор

- Python: **115 passed / 3 skipped**, **2,56 с**, включая **18 тестов агента**. Пропущены три проверки, ожидающие исходные файлы в репозиторном `data/official`; реальный набор отдельно проверен из внешней папки.
- Граф: **8 Node-тестов прошли** (`node --test frontend/src/components/graph-layout.test.js`). Production-сборка frontend завершилась успешно; проверенный прогон — **1,07 с**.
- Два запуска CLI на официальных Parquet: **2 248 узлов**, **3 119 направленных пар**, **4 840 операций**, **66 кластеров**, **50 кандидатов без seed**; время **0,72 / 0,71 с**. Все три CSV совпали побайтно.
- Сохраняются 81 seed, 19 изолятов и защита 444 листьев четвёртого перехода. Дневные даты не трактуются как точное время. Основное аналитическое ядро и экспорт не требуют OpenAI.

### Новый интерфейс

- Первый экран проверен по браузерному снимку при **1280×720**: очередь проверки, локальный граф выбранного счёта и карточка оснований образуют единое рабочее пространство. По умолчанию показано до четырёх крупнейших контрагентов на сторону; доступны 8 / 12 и «Вся сеть».
- Кнопка «Обзор за 60 секунд» открывает рабочее модальное окно с назначением продукта и критериями. Рубрика показана как веса, не самооценка команды.
- Во вкладке «AI-проверка» видны итог, факты и журнал фактических вызовов с GID. После успеха журнал свёрнут и раскрывается кликом; параметры повторной проверки вынесены в раскрываемый блок. Переход по предложенному `X` обновил карточку и граф.
- На официальном наборе поиск полного GID `100000008603629100` выбрал нужный счёт; модальное окно оснований с исходными операциями открылось.
- Браузерный экспорт подтверждён файлом `Downloads/moneygraph-results.zip`: **94 491 байт**, время изменения **23 сентября 2026, 17:08:45 UTC+05**, совпадающее с нажатием кнопки. В архиве ровно три CSV: **2 248 строк ролей**, **66 кластеров**, **50 кандидатов** (без строк заголовков). Ожидание автоматического download-event завершилось таймаутом 15 с, но проверка фактически сохранённого ZIP подтвердила успешность экспорта; это ограничение наблюдения инструмента, не потерянная загрузка.
- Ошибок JavaScript в консоли не зафиксировано. Есть неблокирующее предупреждение Cytoscape о `wheelSensitivity`.
- Адаптированы два компонента 21st.dev: `StatsCard` и `AgentActivity`. Их происхождение и оговорки об условиях использования — в [docs/UI_SOURCES.md](docs/UI_SOURCES.md). Демонстрационные события и скрытые рассуждения не используются.
- Новая мобильная версия в этой записи не объявляется проверенной по историческому скриншоту прежнего интерфейса.

### Live OpenAI: результаты и ограничение проверки

1. **Первый вызов на синтетическом demo:** HTTP 200, `mode=agent, status=completed`, **14,75 с**. Выполнены четыре реальных вызова: `get_account → get_connections → get_account → get_account`. Получены три факта и следующий кандидат `X`.
2. **Второй вызов в браузере, до последней корректировки:** `mode=agent, status=limited` после четырёх вызовов. Журнал показан честно; подтверждённое итоговое решение отсутствует. Этот случай не скрывается успешным первым запросом.
3. **Корректировка после второго вызова:** последний ход модели зарезервирован для итога (`tool_choice=none`), бюджеты передаются явно, повтор уже успешно выполненного запроса к данным отклоняется. Общий бюджет — 45 секунд с сетевыми таймаутами, не строгая wall-clock гарантия. Автоматические проверки после изменений прошли.
4. **Финальный браузерный live-запуск после корректировки:** synthetic `F`, `agent/completed`; три вызова `get_account(F) → get_connections(F) → get_account(X)`, три факта, следующий кандидат `X`. Журнал с идентификаторами и факты реально показаны в интерфейсе. Время этого запуска не измерялось.
5. **Повтор после уплотнения карточки результата:** снова `agent/completed`, три вызова и кандидат `X`; в этот раз модель выбрала четыре подтверждённых факта. Итог виден без раскрытия формы, журнал свёрнут. Сборка этой версии завершилась за 1,05 с. Число выбранных фактов не обязано повторяться.

Внешние live-вызовы проводились только на синтетическом наборе. Новый агент **не проверялся живым вызовом OpenAI на официальной выгрузке**. Ни наличие ключа, ни успешный ответ на demo не подтверждают такую проверку. Порядок инструментов выбирается моделью и может отличаться между запусками.

- Полный граф содержит **35 слабосвязных компонент**, включая 19 изолятов. Все узлы сохранены в расчётах и выгрузках.
