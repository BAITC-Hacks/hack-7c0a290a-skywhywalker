# Работа команды

Основной продукт — единое приложение React/FastAPI из корня репозитория. Командный main дал контракт кейса и правила ролей; MoneyGraph experiment — интерактивный интерфейс, аномалии и AI-функции; design — идеи компактного рабочего пространства. Подробнее: [сравнение MVP](docs/MVP_COMPARISON.md).

- Изменения готовятся в отдельных ветках и проверяются через pull request.
- Изменения API, шести ролей или трёх CSV сопровождаются тестами и документацией.
- Перед объединением: `python -m pytest tests -q` и `pnpm build` из `frontend`. Изменения интерфейса проверяются в браузере.
- Официальные Parquet остаются локально в `data/official`. Не добавляйте в Git исходные данные кейса, `.env`, ключи, виртуальные окружения и `node_modules`.
- GID передаются строками. Изоляты, seed, границы четвёртого перехода и дневная точность сохраняются при любых преобразованиях.
- Результаты обновляются в [VERIFICATION.md](VERIFICATION.md). Прежняя проверка отдельной ветки не считается проверкой интеграции.
