# Проверка двух MVP и готовности к демонстрации

Проверка 23.09.2026. Ветки не объединены. `main` и исходники сокомандника не изменялись.

## Что было не так с первым переносом макета

Браузерная проверка выявила разрыв, который не находили AppTest: боковая панель 300 px, чрезмерные промежутки между Streamlit-блоками, заголовок под служебной панелью, сжатие двух колонок на узком экране, пересечения подписей Plotly и слишком мелкие маркеры. Цвет был перенесён, композиция и граф — нет. Поэтому прежнее утверждение о готовом дизайне было преждевременным.

Новый обзор — цельный HTML/CSS-компонент с контролируемой сеткой, компактными показателями и картой потоков. SVG строится из реальных рёбер, не из сгенерированного изображения. В Streamlit SVG передаётся как data-URI изображение с обычными HTML-ссылками поверх узлов: это сохраняет безопасную HTML-санитизацию. Полный интерактивный граф остаётся в разделе расследования.

## Сравнение кандидатов

| Проверка | MoneyMap / design | MoneyGraph AI / experiment |
| --- | --- | --- |
| Данные по умолчанию | Выданные parquet, 2 248 узлов / 4 840 переводов | Синтетическое демо, 42 account / 172 перевода |
| Аналитическое ядро | Шесть ролей, seed/depth, кластеры, очередь non-seed | Общие паттерны, Isolation Forest, FIFO |
| Три CSV по кейсу | Есть | В альтернативном приложении нет |
| Полный набор кейса | Обрабатывается, все узлы сохранены | CSV-парсер отклоняет более 1 500 узлов |
| Увеличить только лимит | Не требуется | Недостаточно: потеряются 19 изолированных узлов |
| Ограничение 4-го колена | Учитывается, 444 узла не считаются конечными | Вход не содержит seed/depth; обработки нет |
| Графический интерфейс | Streamlit; обзор переделан, подробный граф Plotly | React/Cytoscape; больше интерактивности, точнее управление вёрсткой |
| Визуальный стиль до проверки | Светлый, но слабое соответствие макету | Цельный тёмный, не светлая палитра Freedom |
| AI | Код есть, живой запрос не подтверждён | Правила/fallback подтверждены, живой OpenAI не проверялся |
| Проверки | Повторный расчёт сверён с результатами, UI и HTML/SVG тесты | Production build и 19 тестов успешно выполнены независимо |

Отдельный риск альтернативного backend: в исходных транзакциях кейса есть даты, но нет внутридневного времени. После parse время 00:00; FIFO-порог 60 минут на таких данных нельзя выдавать за доказанный быстрый транзит. Нужен дневной признак с явным ограничением либо отключение этого сигнала.

## Честная готовность

**Аналитический MVP готов на фиксированном наборе кейса.** Повторный расчёт совпал с CSV; все 2 248 GID сохранены; top-50 состоит из ранее неизвестных узлов. Это не валидация качества модели на размеченных ответах — таких ответов нет.

**Единый презентационный продукт ещё не завершён.** Два кандидата не интегрированы. Нет подтверждённой публичной установки, успешного живого запроса OpenAI, авторизации, истории решений аналитика или импорта произвольной новой выгрузки в MoneyMap. Замена parquet при существующих CSV не вызывает автоматический перерасчёт.

## Решение для команды

Сохранить `pipeline.py` источником ролей и трёх CSV. Если основным выбирается React, адаптировать его API к этой аналитике, а не переносить демонстрационные эвристики поверх кейса. Передавать GID строками, загружать все узлы из nodes, показывать локальный подграф выбранного узла и агрегированные рёбра. Не пытаться отрисовать все 4 840 транзакций с длинными подписями одновременно.

До готовности интеграции MoneyMap остаётся рабочим демонстрационным вариантом на настоящих данных. Не сливать ветки вслепую: отсутствие текстовых конфликтов не создаёт связи между двумя приложениями.
