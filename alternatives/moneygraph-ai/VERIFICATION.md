# Проверка MoneyGraph AI

Дата: 23 сентября 2026.

## Текущая русская версия

- Python-исходники backend успешно прошли compileall.
- Прошли четыре изолированные проверки AI-модуля: русский резервный ответ, имитация структурированного ответа OpenAI с независимыми серверными показателями, безопасные сообщения об ошибках и обработка неверного ответа. Использованы настоящий Pydantic и тестовая замена OpenAI; это не проверка настоящего SDK или API.
- Добавлены pytest-тесты локализации, защиты рассчитанных показателей и ошибок 401/403/429. Полный pytest после этих изменений не запускался.
- Новая frontend-сборка, проверка в браузере и настоящий запрос OpenAI пока не выполнены: среда блокирует доступ к установленному Python и frontend-зависимостям; сетевую установку зависимостей также отклонила автоматическая проверка разрешений.
- Наличие ключа в локальном .env не подтверждает его работоспособность. Для использования нового интерфейса нужны pnpm build и перезапуск backend.
- Текущий архив русской версии содержит только исходники; .env, .venv, node_modules, frontend/dist и загруженные данные исключены.
- Публичное развёртывание не выполнено.

## Проверки предыдущей версии до обновления

- Backend: 19 тестов прошли; одно предупреждение Starlette/TestClient.
- Vite production build прошёл.
- Браузер: 1600×1100 и 390×844; без ошибок JavaScript и горизонтального переполнения.
- Проверены демонстрационный набор, CSV-загрузка и анализ, поиск, повторный выбор счёта, фильтры, глубина 1–4, объяснение, основания, сравнение F/D, сводка, возврат к демонстрации.
- Проверены резервные ответы без ключа и при ошибках. Настоящий OpenAI не вызывался.

Эти прежние результаты не подтверждают новую сборку или новый дизайн.
