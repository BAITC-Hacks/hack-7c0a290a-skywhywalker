# Проверка MoneyGraph AI

Дата: 23 сентября 2026.

## Текущая русская версия

- Backend: **24 теста прошли** (`python -m pytest tests -q`), одно предупреждение `StarletteDeprecationWarning`. Проверки включают локализацию, сохранность рассчитанных сервером показателей, резервные ответы и обработку ошибок OpenAI 401/403/429.
- Frontend: **Vite production build прошёл** для текущего русского интерфейса.
- Настоящий запрос `POST /api/ai/explain-node` для счёта F к проверяемому серверу `http://127.0.0.1:8001` вернул русский ответ, `mode=openai`, `reason=null`. `/api/health` вернул `ai_configured=true`. Это успешная проверка реального OpenAI API; другие AI-сценарии этим запросом не проверялись.
- В браузере просмотрены скриншоты настольного интерфейса шириной 1254 px и мобильного интерфейса 390×844. Горизонтального переполнения нет: `scrollWidth` составил 1239 и 375 px соответственно. Исправлено наложение суммы в карточке статистики.
- Проверены справка «Как пользоваться», выбор счёта D, русские «Основания» и исходные переводы, «Проследить связи» и сброс. В проверенном сценарии глубина 1 показывала 2 узла, глубина 4 — 12 узлов.
- Действие WebMCP `select_moneygraph_account` успешно выбрало счёт D.
- Независимый аудит содержимого `frontend/dist` и подготовленной для Git копии проекта не обнаружил фактический ключ из локального `.env`. Значение ключа не выводилось и не включалось в отчёт.
- Публичное развёртывание не выполнялось. Для OpenAI на другом компьютере нужен собственный локальный `.env` и перезапуск backend.

## Кандидат в Git

- Исходники находятся в `alternatives/moneygraph-ai` в отдельной ветке `experiment/moneygraph-ai-mvp`. Корневой командный MVP и `main` не меняются.
- В Git не включены `.env`, `.venv`, `node_modules`, `frontend/dist` и пользовательские наборы данных. Сборка frontend создаётся командами из [README.md](README.md).
- Для нового checkout используется порт 8000 по умолчанию. Порт 8001 выше относится только к локальному серверу, на котором проведена проверка.
