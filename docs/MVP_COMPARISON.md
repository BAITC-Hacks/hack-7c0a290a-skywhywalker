# Как объединены MVP

Сравнение основано на исходниках: командный `main` — `4a2df53`, `experiment/moneygraph-ai-mvp` — `c7c3f24`, `design/moneymap-workspace` — `161f6e2`. Единая версия использует одно приложение React/FastAPI и один расчёт для интерфейса и CSV.

| Возможность | Командный main | MoneyGraph experiment | Единая версия |
|---|---|---|---|
| Данные | Три Parquet, seed и глубина | CSV и синтетическое демо | Официальные Parquet/ZIP, CSV и учебное демо |
| Изоляты | Сохраняются из nodes | Граф строился по операциям | Сохраняются все 2 248 счетов |
| Роли | Шесть правил с ограничениями seed/depth | Несколько паттернов на счёт | Шесть ролей и отдельные паттерны |
| Приоритет | Центральности, объём, seed, структура и роль | Граф, Isolation Forest, паттерны, FIFO | Компоненты с исключением недоступного потока, коэффициенты seed и границы |
| Время | Совпадение дат до двух дней | FIFO для точных временных отметок | Точность определяется при импорте; минутные сигналы отключены для дат |
| Интерфейс | Streamlit/Plotly | React/Cytoscape, русский интерфейс и основания | React/Cytoscape с официальными данными, ролями, группами и экспортом |
| CSV кейса | Есть | Отдельного контракта кейса не было | Три CSV из того же анализа, что использует сайт |
| ИИ | Текстовая справка по фактам | Объяснение, сравнение, вопросы и резервные ответы | Функции experiment с ролями, границами и точностью дат в контексте |

## Вклад design

`pipeline.py` в design совпадает с main. Улучшения относятся к представлению: компактный обзор, заметный выбранный счёт, схема «плательщики → счёт → получатели», очередь проверки и постепенное раскрытие деталей. Полные GID в ссылках и таблицах передаются строками.

Эти принципы служат ориентиром единого интерфейса. Streamlit-компоненты, встроенная HTML/SVG-навигация и его состояние не переносятся как второе приложение. Интерактивность и API остаются в React/FastAPI.

## Изменения аналитики

Сохранены шесть машинных ролей, численные основания, seed/depth и формат CSV. Приоритет отличается от прежнего main: он использует компоненты MoneyGraph с Isolation Forest и явным учётом доступности данных. Совпадение старого и нового рейтингов не является условием корректности.

В API приоритет — 0–100; CSV содержит тот же результат, делённый на 100. `role_score` — сила правила. «Координатор» описывает положение в сети, а не причастность к преступлению.

Значения 00:00 в официальных данных служат техническим представлением даты и не доказывают переводы за час. Изоляты сохраняются независимо от операций; граница четвёртого перехода не становится автоматически конечными получателями.

## Проверенный результат

Официальный набор: 2 248 счетов, 3 119 пар, 4 840 операций, 81 seed, 19 изолятов, 444 узла четвёртого перехода. Полный граф содержит 35 слабосвязных компонент. Текущий расчёт дал 66 групп Louvain и top-50 без известных seed.

Полный pytest: **100 passed**, одно предупреждение Starlette. Production-сборка прошла. Браузерная проверка отслеживается в [VERIFICATION.md](../VERIFICATION.md). Старые отчёты отдельных веток не заменяют проверку объединённой версии.
