# Компоненты интерфейса: 21st.dev

23 сентября 2026 исходный код двух компонентов получен через официальный
`https://21st.dev/api/mcp`, инструменты `search` и `get_component`.
Ключ хранится вне репозитория; приложение не обращается к 21st во время работы.

| Исходный компонент | Автор | Локальная адаптация |
|---|---|---|
| [Stats Card](https://21st.dev/@ravikatiyar162/components/stats-card-1), demo 8321 | Ravi Katiyar (`ravikatiyar162`) | `frontend/src/components/ui/StatsCard.jsx` |
| [Agent Activity](https://21st.dev/@starc007/components/agent-activity), demo 29318 | `starc007`, beui.dev | `frontend/src/components/ui/AgentActivity.jsx` |

Адаптации выполнены под существующий React/JSX и локальную палитру:
карточки используют реальные показатели вместо демонстрационных трендов;
журнал показывает только фактические вызовы инструментов с сервера.
Демонстрационные события, скрытые рассуждения, превью, видео и фотографии
авторов не включались. Анимационная зависимость заменена доступным
раскрытием списка и CSS с учётом reduced motion. Ссылки на оригиналы
сохранены в коде и разделе «Об интерфейсе» приложения.

Это адаптации сторонних компонентов, а не заявление об их авторстве командой.
Лицензионные условия исходных компонентов определяются их авторами и площадкой;
MCP-ответ не содержал отдельного текста лицензии. Перед распространением
за пределами хакатона проверьте условия конкретных компонентов.
